# Site Institucional - Dr. Davi Bastos | Advocacia e Consultoria

Repositório oficial do site institucional desenvolvido para o escritório de advocacia e consultoria do **Dr. Carlos Davi Vieira Bastos**.

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Estruturação semântica das páginas)
* **CSS3** (Estilização personalizada, layout responsivo e paleta profissional)
* **JavaScript** (Controle de modais e interatividade)
* **FontAwesome** (Ícones institucionais)
* **Google Fonts** (Tipografia profissional - Cinzel e Open Sans)

## 📱 Funcionalidades
* Design responsivo adaptado para computadores, tablets e smartphones.
* Seção "Sobre" com biografia e apresentação profissional.
* Áreas de atuação com janelas modais (pop-ups) detalhando os serviços prestados.
* Integração direta com WhatsApp para captação de clientes.
* Localização interativa integrada com o Google Maps.
